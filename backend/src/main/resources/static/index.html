Video Diagnosis MVP

上传、抽帧、ASR、诊断，一页就能跑通。

这是一个最小可用的短视频对比诊断前端页。它直接连后端接口， 你可以在这里完成视频上传、任务创建、结果查询和建议查看，不需要再切换多个工具。

1. 上传视频

上传后会自动触发抽帧和 ASR，成功后你可以直接把返回的视频 ID 拿去创建任务。

{ "hint": "上传结果会显示在这里" }
提示：上传成功后，复制返回的 `videoId` 去下方创建分析任务。

2. 创建分析任务

填写目标视频和参考视频，点击创建后会返回一个任务 ID。重复提交同样输入会复用同一个任务。

{ "hint": "任务创建结果会显示在这里" }

3. 查询任务状态

输入任务 ID 后，可以看状态、进度、开始时间和结束时间。

{ "hint": "查询结果会显示在这里" }

4. 最近数据

这里会记录你最近一次上传、创建任务和查询结果，方便你联调时快速回看。
